Case File — Blackstone Carried Interest

Blackstone Carry Docket

Two branches of one review. A six-agent chain of custody that walks a carry disclosure from raw filing to a graded verdict — and a deterministic waterfall calculator that does the carry math in real code, per fund, with its own limits printed on the page.

This page documents the pipeline; it does not run it. All six stages call the Anthropic Messages API with no key in the client — which only ever worked inside Claude's own artifact sandbox, where the request is proxied and authenticated invisibly. A published page can't reach that endpoint, so what's rendered here is the architecture itself: every stage's real system prompt, its model settings, and exactly what it is and isn't allowed to see. Branch 2's calculator is plain arithmetic and runs in full.

Standard assumptions, not Blackstone's disclosed terms. An 8% hurdle, 100% catch-up and 20% carry on a European whole-fund waterfall. Branch 1's own retriever found real disclosed hurdles ranging 5–10% by filing year and vehicle type, which this flat assumption does not match. This is a teaching model for how the waterfall works — not an economic estimate for any fund.

Select fund

Data. Blackstone fund performance reference table, figures as of June 30, 2026. Committed and available capital in $B; MOIC and net IRR as reported. Of the 35 vehicles listed, 27 carry enough public data for a time-based calculation; the remaining 8 are shown but not computed. A further 8 of the computed funds return a flag instead of an effective-carry figure, where the arithmetic is sound but the answer would mislead.

Method. Paid-in capital is committed less available. Years elapsed run from the midpoint of the deployment window to the June 2026 report date, floored at 0.1 and capped at 12 — a typical closed-end fund life — so realized funds stop accruing hurdle once they are actually done. Every figure on this page comes from the same computeCarry function that produces the CSV, so the export and the screen reconcile line for line.

Provenance. Rendered from carry-review.jsx on branch claude/session-completion-checklist-5nb1jo of the Blackstone-Carry-Project repository. The waterfall math, the fund table, the warning thresholds and the six system prompts are reproduced unchanged from that source.
